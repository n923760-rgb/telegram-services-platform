# Bounded local printed-text recognition

Baseline: main `02d11c87f2241e8034290365809d32a4b79a16f6`, merged PDF PR #25.
Both reviewed-head workflow `37918022653` and main workflow `37918332000` passed.
Owner authorized incremental implementation, publication and merge after checks.

## Scope and implementation

Add default-disabled `local_ocr`, SAR 2.00 administrator-issued test credit.
Use an abstract injected document provider; no bot/core/service-slug branches,
financial-policy changes, Python dependencies or migrations. The old vision OCR
contract remains unchanged. No AI provider is constructed and no fallback is made.
Source language selects native Arabic/English/mixed recognition, not translation.

Native execution is serialized per worker process with bounded wait. Fixed command
arguments, no shell, temporary private directories and suppressed child output.
Each native child: 512 MiB address space, 20 CPU seconds, 25 wall seconds, 2 MiB
file output, zero core dump and one OpenMP thread. Timeout/cancellation kills and
reaps the process group before cleanup. This is trusted native execution with
resource bounds, not a sandbox. Existing worker concurrency remains unchanged.

Five images, 10 MiB each/20 MiB total; existing decoded-pixel/EXIF and 1024-pixel
intake preserved. Output capped at 50,000 characters. TSV lines follow native
word ordering; no numeric replacement/reformatting. Mean confidence <0.70 and
numeric-word confidence <0.85 are rejection heuristics, not proof of correctness.
Long results add TXT; no page layout, tables or Word reconstruction. Users must
compare recognized text/numbers with their source.

Docker installs distribution Tesseract/Arabic/English packages only in a worker
build target. CI installs the same package families for mandatory native tests,
and adds actual non-root worker image build/recognition with network disabled.
No model binaries are committed. See docs/DOCUMENT_ENGINES.md for attribution.

## Evidence and limits

- PASS: 33 local independent tests, lint/format and whitespace.
- PASS: Actual Tesseract 5.3.4 on generated DejaVu printed text: Arabic, English,
  mixed; English leading-zero identifier 00123, amount 125.50 and date 2026-10-09
  compared exactly. Multi-image source order and no-text rejection tested.
- Local Arabic data: official tessdata_fast upstream blob
  `c8d129c67821c1592cac46836686b057ecc203dc`, SHA-256
  `e3206d3dc87fd50c24a0fb9f01838615911d25168f4e64415244b67d2bb3e729`.
  Test-only tessdata override; production uses distribution packages instead.
- Unit cases cover malformed TSV, nonfinite/out-of-range confidence, uncertain
  numbers, output bounds, invalid images, cancellation, group kill/cleanup and
  shared concurrency. Full suite collects 481 tests.
- Added lifecycle cases: actual native recognition, capture once, no AI cost/holds,
  failure release, ownership, prepared-result delivery recovery, busy retry and
  invalid-input rejection before reservation. Full DB/Redis checks NOT RUN locally.
- Hosted workflow and image qualification must pass on the exact published head
  before merge; the PR retains final run IDs/results separately.
- NOT RUN: Real customer-image fidelity, dense pages, handwriting, representative
  Arabic numeric content, native table/layout reconstruction, real Telegram journey,
  server load/restart qualification, production deployment or service enablement.
